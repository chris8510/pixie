## English (en-US)

### Product name
Pixie – Desktop Pet

### Short description *(max. 1000 characters)*
A tiny desktop pet that shows what Claude Code is doing – task, current step and a colour-coded status – without switching windows. Ask Claude with a click or by voice, transcribed locally on your PC. Works with Codex pets.

### Description *(max. 10,000 characters)*
Pixie sits in a corner of your screen as a small animated pet and keeps an eye on Claude Code for you. You always see what your coding agent is up to – even while you work in another window.

What Pixie shows:
• The task you gave Claude and the step it's on, e.g. "Editing LoginForm.tsx"
• A coloured dot: blue = working, yellow = needs you, green = done, red = blocked
• A notification when Claude needs your permission or an answer
• "Done" stays until you've seen it – no result gets missed

What you can do with Pixie:
• Ask Claude a quick question or run quick actions like "What changed?" or "Suggest a commit message"
• Ask by voice – speech is transcribed with Whisper entirely on your PC, no account, no upload
• Click the pet, drag it around, change its size; it looks at your mouse and falls asleep when nothing's going on
• Follow several Claude Code sessions at once

Your own pets:
Pixie plays pets in the Codex pet format. Pets made for Codex work unchanged; your own pets go into a folder. Pixelchen and Pricklet come built in. With the free "pixie-pet" Claude skill, Claude can even design a completely new pet for you.

Requirements:
Pixie works with Claude Code running on your PC (in a terminal or in the "Code" section of the Claude app). One click on "Connect to Claude Code" sets everything up. Pixie can't follow cloud chats.

Privacy:
Everything stays on your computer. Pixie collects no data and has no ads or tracking.

Pixie is an independent open-source project (MIT license), not affiliated with Anthropic or OpenAI. "Claude" and "Claude Code" are trademarks of Anthropic; "Codex" is a trademark of OpenAI.

### Restricted capability: runFullTrust – justification
> Pixie is a desktop overlay built with Electron. It needs full trust to read and write Claude Code's settings file in the user's profile (to add/remove its hooks, with a backup), to run a local HTTP endpoint on 127.0.0.1 that receives status messages from Claude Code, and to start the user's own Claude Code command-line tool for quick questions.

### Notes for certification
> Pixie shows the status of Claude Code (Anthropic's coding CLI) running on the same PC. Without Claude Code it still runs: the pet appears in the bottom-right corner; right-click it for the menu (switch pets, "Customize pet…" for the size, settings), hover it for the buttons. To simulate Claude Code activity, run in PowerShell:
> `Invoke-RestMethod -Method Post -Uri http://127.0.0.1:47821/state -Headers @{ 'X-Pixie' = '1' } -ContentType 'application/json' -Body '{"state":"working","task":"Certification test","message":"Editing a file"}'`
> The microphone is only used when the microphone button is clicked; speech is transcribed locally (the speech model is downloaded once from huggingface.co on first use).
